Wholesale Tiers

Approved wholesale customers get 10% off at 12+ units, 15% at 24+ and 20% at 48+, applied automatically at checkout. A progress bar shows how many more units unlock the next tier. The merchant approves customers in the admin; tiers live in one config read by both the Function and the checkout block.

How it decides


customer.$app:wholesale_approved == "true"?        no → no discount
eligible lines = product variants without the "no-wholesale" tag
units          = sum of eligible quantities
tier           = highest tier in shop.$app:wholesale_tiers with minQuantity ≤ units
→ one product discount on every eligible line: "Wholesale 15% (24+ units)"

      
    
        
  • One source of truth. The Function can read customer tags but a checkout extension cannot, so eligibility is an app-owned customer metafield both can read, and the tiers are one shop metafield. Both are declared in shopify.app.toml, so they appear in the admin on install.
    • 
        
  • Fail closed. A missing or malformed tier table gives no discount, never a wrong one; any tier above 50% is ignored.
    • 
        
  • No personal data reaches the Function: it reads one boolean on the customer.
